ON-DEVICE AI · ANDROID · SPEC §12 SCREEN SET

Fifteen screens for a runtime-locked local inference app

Nocturne on a 392×824 Android viewport. Five bottom destinations — Chat, Image, Voice, Models, Settings — because §12's ten screens collapse into four modalities plus system config; everything else is a push or a sheet inside one of them.

Principle §1.5

Zero parameter widgets. The Expert screen is one generic renderer over the manifest — rows carry their own type, tier, help and dependsOn. S8 shows four widget types from the same code path.

Principle §1.2

Refusal is a designed state, not an error toast. S2 shows the fit arithmetic recomputing live under the context slider; S5 shows the four ways a repo can be turned down, each with a remedy.

Colour discipline

Verdicts don't use red or green — the palette is mono. Accent means runnable, an accent outline means caveat, and neutral-800 with a slash mark means no. Weight comes from the mark, not the hue.
